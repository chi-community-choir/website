# Documentation Directory

Welcome to the Chichester Community Choir website documentation!

This directory contains templates and guides for managing website content.

## Directory Structure

```
docs/
├── README.md           ← You are here
├── templates/          ← Ready-to-use templates
│   ├── post-template.md    - Blog post template
│   └── song-template.md    - Repertoire song template
└── guides/             ← Detailed how-to guides
    ├── adding-posts.md     - Complete guide for blog posts
    └── adding-songs.md     - Complete guide for repertoire songs
```

## Quick Start

### I want to add a blog post
1. Copy the template: `templates/post-template.md`
2. Read the guide: `guides/adding-posts.md`
3. Create file in: `content/posts/`

### I want to add a song to repertoire
1. Copy the template: `templates/song-template.md`
2. Read the guide: `guides/adding-songs.md`
3. Create file in: `content/songs/`
